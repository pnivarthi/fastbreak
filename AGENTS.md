# Working on Fastbreak

Fastbreak is a hands-on learning project for a developer experienced in Python
who is learning Go, system design, database performance, replication, and
distributed computing.

- Teach in small, runnable steps. Explain the current change and the reason for it.
- Use Python comparisons when helpful, and clarify where the analogy breaks down.
- Leave room for the user to implement and experiment. Do not build whole future
  stages unless the user asks.
- Prefer simple, idiomatic Go and the standard library initially. Introduce
  abstractions, dependencies, and services when there is a concrete reason.
- For performance work: predict, implement, measure, explain. Track throughput,
  latency distributions, errors, and resource use rather than chasing RPS alone.
- Use the real NBA dataset. Clearly label any simulated events added later.
- Read LEARNING.md for the roadmap and update its progress when a stage changes.
